# ChronoDino-Android-Game

ChronoDino is an Android-based virtual pet survival game developed using Java and Android Studio. In this game, players are responsible for keeping a dinosaur alive by feeding it before its life timer runs out.

The dinosaur starts with **60 seconds of life**, and the timer continuously decreases over time. Feeding the dinosaur restores its timer and earns points. If the dinosaur is not fed, it becomes hungry and warns the player. During the final **10 seconds**, the dinosaur cries and displays starvation messages. When the timer reaches zero, the dinosaur dies and the game ends.

To keep the dinosaur alive, players can choose from three food options.

Each food item provides a different score value. The dinosaur may also randomly develop a **food craving**. Feeding the dinosaur its desired food rewards the player with **2× bonus points**, making strategic feeding important for achieving higher scores.

The game includes a **High Score System** that stores the player's best score, encouraging replayability and competition to beat previous records.

## Features

- Real-time 60-second survival timer
- Interactive virtual dinosaur pet
- Multiple food options with unique point values
- Random food craving system
- Double points bonus for satisfying cravings
- Hunger warnings and starvation alerts
- Game Over system when the timer reaches zero
- High score tracking and persistence
- Simple and user-friendly Android interface

## Gameplay

1. Start the game with a dinosaur that has 60 seconds of life.
2. Feed the dinosaur using Apple, Chicken, or Fruit.
3. Earn points while restoring the life timer.
4. Watch for special food cravings.
5. Feed the correct food to earn 2× bonus points.
6. Prevent the timer from reaching zero.
7. Achieve the highest score possible and beat your previous record.
